# נטע · האפליקציה

הדף שמוגש למשתמשים. קובץ אחד, בלי תלויות ובלי שלב בנייה בצד הלקוח.

**זה לא הריפו של הפרויקט.** האפיון, סכימת המסד, כללי ההרשאות והבדיקות חיים
בריפו הפרטי `Neta`. כאן יושב רק מה שדפדפן מוריד ממילא כשהוא נכנס לאתר, ולכן
אין כאן מה להסתיר.

`index.html` נבנה מתוך הריפו הפרטי (`web/build.sh`) ולא נערך כאן ישירות —
עריכה כאן תידרס בבנייה הבאה.

## המפתח שבקובץ

בקובץ יש כתובת של פרויקט Supabase ומפתח גישה. הוא מיועד להיות גלוי: מה שמגן
על הנתונים הוא כללי ההרשאות שבמסד, לא סודיות המפתח. מפתח `service_role`,
שכן עוקף את הכללים, אינו נמצא כאן ולא ייכנס לכאן.

הפרויקט שמחובר כרגע הוא **סביבת פיתוח**. אין בו נתונים של אנשים אמיתיים.
